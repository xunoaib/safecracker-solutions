## Solution

The 4-digit display is glitchy -- each digit only shows a partial set of 7-segment bars, narrowing it to a handful of possible digits. After each guess, the number of retracting bars tells you how many digits are correct and in the correct position (mastermind-style feedback). Use that to narrow the candidates down to one code.

**Solution:** `8796`
