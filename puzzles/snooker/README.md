## Solution

A full snooker set has 15 reds and 1 each of yellow/green/brown/blue/pink/black. Count which balls are missing from the table and pockets, then enter their point values (red=1, yellow=2, green=3, brown=4, blue=5, pink=6, black=7) in order: 2 missing reds, 1 missing green, 1 missing black.

**Solution:** `1137`
