## Solution

A smaller version of the [Eight queens puzzle](https://en.wikipedia.org/wiki/Eight_queens_puzzle). Place one marker per row on the 6x6 grid so that no two markers share a column or diagonal. Place them at (row, column):

```
(0, 1), (1, 3), (2, 5), (3, 0), (4, 2), (5, 4)
```
