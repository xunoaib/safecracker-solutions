## Solution

Magnetic buttons essentially "tilt" the box to roll the ball through the maze. It slides in a straight line until it hits a wall, falls off screen, or reaches the target. The moves below are grouped in fours for readability (U=up, D=down, L=left, R=right):

```
URDL DRDL URUR URDR DLUR D
```
