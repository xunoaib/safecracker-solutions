## Solution

Each of the 5 wheels (numbered 0-4, top to bottom) advances a pair of metal bars one step through a closed -> retracting -> open -> extending cycle when turned. Turn the wheels below in order (by number) until all 6 bars reach the open position:

```
0 0 0 2 3 4
```
